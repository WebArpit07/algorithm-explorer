Linear Search

Rosen §3.1 (Alg. 2)

Sequentially traverses an arbitrary sequence. Requires zero preprocessing or preconditions.

Best Case: Θ(1)
Worst Case: Θ(n) (n comparisons)
Average Case: Θ(n) ((n+1)/2)

Binary Search

Rosen §3.1 (Alg. 3)

Logarithmic divide-and-conquer probing. Halves the search space on each iteration.

Precondition: Sorted sequence
Worst Case: Θ(log n) (2⌊log₂ n⌋ + 2)
Speedup at 100k: ≈ 1,946×

Bubble Sort

Rosen §3.1 (Alg. 4)

Adjacent exchange sort. Fixed-pass formulation without early exit preserves exact operation invariance.

Comparisons: Θ(n²) (n(n-1)/2 invariant)
Best Swaps: 0 (Sorted)
Worst Swaps: n(n-1)/2 (Reverse)

Insertion Sort

Rosen §3.1 (Alg. 5)

Incremental insertion into a sorted prefix. Highly adaptive to existing input order.

Best Case: Θ(n) (n - 1 comparisons)
Worst Case: Θ(n²) (n(n-1)/2 shifts)
Inversion Identity: Shifts ≡ Swaps
